# Car Dealership Web Application

## Project Overview
This capstone project is a full-stack web application for a national car dealership network. It allows users to browse dealership locations across states, read customer reviews, post new dealership reviews with sentiment analysis, and manage account credentials.

- **Tech Stack:** Django, React, Express/Node.js, IBM Cloud Code Engine, Sentiment Analyzer Microservice

## Features
- Dynamic dealer listing and filtering by US State
- User Authentication (Login, Logout, Sign-Up)
- Microservice integration for sentiment analysis on customer reviews
- CI/CD automation pipeline using GitHub Actions
